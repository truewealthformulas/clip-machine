Privacy Policy – The Success Club (Clip Machine)

Last updated: October 23, 2026

Clip Machine is a private tool used only by The Success Club (truewealthformulas@gmail.com) to publish short video clips to its own YouTube, Instagram, Facebook and TikTok accounts.

What data the app uses

The app signs in only to The Success Club's own accounts. It uploads videos and reads basic statistics (views, likes, shares) for those videos. It does not collect, store or share personal data about any other person.

How data is stored

Access tokens are stored encrypted (AES-256) and can only be read by the app's own publishing jobs. They are used only to publish and measure The Success Club's own posts. No data is sold or shared with third parties.

TikTok data

When the account owner chooses "Log in with TikTok", the app receives, with the owner's permission:

  • Basic account information (user.info.basic: the account's open ID, display name and avatar), used only to show which TikTok account is connected.
  • Permission to upload or publish videos (video.upload / video.publish), used only to send The Success Club's own clips to that same TikTok account, with the caption, privacy level and interaction settings the owner chooses before each post.

The app does not read followers, messages, other users' content or any data beyond the above. The TikTok login can be removed at any time from TikTok (Settings and privacy → Security → Manage app permissions), after which the app can no longer post. To have stored TikTok data deleted, email the address below; it is deleted within 7 days.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube data is used only to upload and measure videos on The Success Club's own channel.
